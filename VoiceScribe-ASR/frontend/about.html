About VoiceScribe

VoiceScribe is a web-based Automatic Speech Recognition application that converts spoken language into editable text and provides basic text-analysis features.

Project Objective

Demonstrate Automatic Speech Recognition combined with text analysis in a simple full-stack web application for the Text and Speech Analysis subject.

Key Features

  • Live speech-to-text with interim and final results
  • Eight recognition languages
  • Editable transcript, copy, download and save
  • Statistics, keyword extraction and a recognition-status indicator
  • Transcript history stored in SQLite
  • Dark mode and responsive layout

Technology Stack

  • Frontend: HTML5, CSS3, vanilla JavaScript, Web Speech API
  • Backend: Python, Flask, REST API
  • Database: SQLite
